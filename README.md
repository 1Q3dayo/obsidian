# Obsidian Knowledge Base

このリポジトリは Obsidian 用のナレッジベースです。以下のフォルダ構成でクリップ・サマリ・アーカイブを管理しています。

- `10_clip/` : Web Clipper などから取り込んだ生データ。処理後は空になります。
- `11_clip_done/` : 要約やタグ付けを終えたクリップの保管場所。
- `20_ai_summary/` : AI による要約ノート。ファイル名の先頭は `yyyymmdd_` で公開日を表します。
- `99_trash_box/` : 破棄予定のメモや一時ファイル。

## 運用メモ
1. 新しいクリップは `10_clip/` に追加し、必要に応じてプロパティを整備します。
2. クリップを処理したら `20_ai_summary/` に要約を作成し、`git mv` で `11_clip_done/` へ移動します。
3. 要約ファイルは front matter の `created` を ISO 形式に統一し、`yyyymmdd_` プレフィックスを付けます。
4. 不要になったメモは `99_trash_box/` に移し、定期的に整理します。

## Git 運用
- 既存ファイルの移動やリネームは必ず `git mv` を使用してください。
- 画像やバイナリを追加する際は容量に注意し、可能であれば外部ストレージを参照させてください。
- コミット前に `git status` で未追跡ファイルと改名の有無を確認し、意味のある単位でコミットします。

## 既知の命名規則
- クリップ: 元記事のタイトルをそのまま使用。
- 要約: `yyyymmdd_<短い英語/日本語タイトル>.md`。
- タグ: `clippings`, `raw`, `ai_summary` などの標準タグに加え、内容を表す英語タグを最大 5 つ付ける。

## 整頓するプロンプト
```
10_clipフォルダ配下のクリップしたファイルについて、以下の処理を行なってください
1. ファイルの内容を要約したmdファイルを20_ai_summaryに作成してください  
   ただし、元ファイルの上部にあるプロパティ項目は要約後のファイルにも必要です  
   ただし、descruotion部分は超要約に修正してください  
   また、tags: には - ai_summary というタグを付与してください  
   また、tags:はそれだけではなく、記事の属性になる英単語を5つまで付与してください（最低1つは付与してください）
   ファイル名は、yyyymmdd(createdの日付)_   の後に、記事の内容を25文字以内に要約したものにしてください（一見してわかるように日本語でお願いします）
2. 10_clip内の元ファイルの上部にあるプロパティ項目の tags: に - raw というタグを追加してください
3. 10_clip内の元ファイルについて、git管理されている場合はgit mvコマンドで、git管理されていない場合はmvコマンドで11_clip_doneフォルダに移動してください
```
