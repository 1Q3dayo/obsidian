## 概要

AWS MCP Serverの全8ツールを検証。Agent SOP Tools、AWS Knowledge Tools、AWS API Toolsの3カテゴリを実践的に解説。自然言語でAWS操作を実行できる機能を紹介。

## 主要ポイント

### Agent SOP Tools
- aws___retrieve_agent_sop: SOPの検索・詳細取得
- AWSベストプラクティスに沿ったワークフロー提供

### AWS Knowledge Tools
- aws___search_documentation: ドキュメント検索
- aws___read_documentation: マークダウン形式で取得
- aws___recommend: 関連トピック推奨
- aws___list_regions: リージョン一覧
- aws___get_regional_availability: 地域別対応状況

### AWS API Tools
- aws___call_aws: 15,000以上のAPI呼び出し
- aws___suggest_aws_commands: API構文ヘルプ
