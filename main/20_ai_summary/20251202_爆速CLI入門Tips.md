## 概要

CLI初心者向けに「最初に知りたかった」Tipsを紹介。キーバインド、tldr、help/man、英語翻訳、日本語manなど、CLIを使いこなすための基礎知識を解説。

## 自分の使っているシェルを確認

```bash
# 現在のシェルを確認
echo $0
# ログインシェルを確認
echo $SHELL
```

## キーバインド

### キーバインドの確認

```bash
# キーバインド一覧の表示
bindkey
```

### キーバインドのモード

- **vimモード**: `bindkey -A viins main`
- **emacsモード**: `bindkey -A emacs main`（デフォルト）

### おすすめキーバインド

#### 初級

- `^F`: 1文字右へ移動
- `^B`: 1文字左へ移動
- `^P`: ひとつ前の履歴を呼び出す（↑）
- `^N`: ひとつ次の履歴（↓）
- `^A`: 行頭へ移動
- `^E`: 行末へ移動
- `^D`: カーソル位置の文字を削除
- `^K`: カーソル以降を削除
- `^Y`: ^Kや^Wなどで消したものを貼り付け

#### 中級

- `^Q`: 今入力している行を一時退避
- `^_`: 編集の取り消し
- `^[f`: 単語単位で右へ移動
- `^[b`: 単語単位で左へ移動
- `^[H`: 現在入力中のコマンドのヘルプを開く（zsh固有）

#### 上級者

- `^X^R`: redo（デフォルトで設定されていない）
- `^[e`: 現在行を$EDITORで編集
- `^p`: 入力内容で前方一致検索（履歴）

## 使えるコマンドを増やしたい → tldrで要約チェック

```bash
# tldrをインストール
brew install tlrc

# tldrでwcの使い方を確認
tldr wc
```

実用的な使用例に焦点を当てた、より簡潔なヘルプを確認できる。

## オプションが覚えられない → helpとmanは最高の情報源

```bash
# コマンドのヘルプを確認
tldr --help

# より詳しい情報を確認
man tldr
```

## 英語がつらい

### PLaMo翻訳

- **ブラウザ拡張機能**: ページのレイアウトを崩さずに翻訳
- **CLIツール**: `plamo-translate-cli`でローカル環境で翻訳

```bash
# plamo-translate-cliをインストール
uv tool install plamo-translate-cli

# tldr wcの出力を日本語に翻訳
tldr wc | plamo-translate --to Japanese
```

### manの日本語化

JM Projectの日本語manページをインストール:

```bash
# manの日本語マニュアルページをダウンロード
curl -L -O https://github.com/linux-jm/manual/releases/download/v20251115/man-pages-ja-20251115.tar.gz

# 展開してインストール
tar xfz man-pages-ja-20251115.tar.gz
cd man-pages-ja-20251115
make install
```

### manをカラー表示にする

```bash
export MANPAGER=less
export LESS=-R
export LESS_TERMCAP_mb=$'\e[1;31m'   # 強調 赤
export LESS_TERMCAP_md=$'\e[1;34m'   # 太字 青
export LESS_TERMCAP_me=$'\e[0m'      # reset
export LESS_TERMCAP_so=$'\e[7m'      # 反転
export LESS_TERMCAP_se=$'\e[0m'
export LESS_TERMCAP_us=$'\e[4;32m'   # 下線 緑
export LESS_TERMCAP_ue=$'\e[0m'
```

Neovimでmanを使う場合:

```bash
export MANPAGER='nvim +Man!'
```
