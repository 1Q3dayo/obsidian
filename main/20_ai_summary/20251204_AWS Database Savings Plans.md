## 概要

AWS re:Invent 2025で発表された「Database Savings Plans for AWS Databases」。マネージドデータベースサービスを1年間で一定以上使用することをコミットすることで、最大35%のコスト削減が可能。

## 主な特徴

- **前払い不要**: コミットのみで適用
- **自動適用**: データベースエンジン、インスタンスファミリー、サイズ、展開オプション、AWSリージョンに関係なく自動適用
- **最大35%削減**: 1年間のコミットでコスト削減

## 対象サービス

- Amazon Aurora
- Amazon RDS
- Amazon DynamoDB
- Amazon ElastiCache
- Amazon DocumentDB
- Amazon Neptune
- Amazon Keyspaces (Apache Cassandra用)
- Amazon Timestream
- AWS Database Migration Service
