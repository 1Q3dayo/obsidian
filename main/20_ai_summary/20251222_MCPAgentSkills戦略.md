## 概要

MCPとAgent Skillsの2大技術を整理。MCPは「接続性レイヤー」として道具を提供し、Agent Skillsは「熟練度と手順」を伝承。両者の違いと補完関係、使い分け指針を解説。

## 主要ポイント

### MCP（Model Context Protocol）
- AIと外部データの抽象化レイヤー
- Resources、Tools、Promptsの3要素
- 接続性の民主化、開発スピード向上
- コンテキスト爆発の課題あり

### Agent Skills
- 手順の知恵を部品化
- SKILL.mdを中心としたフォルダ構造
- 遅延ローディングでコンテキスト節約
- エコシステムの発展を促進

### 使い分け
- MCP: 外部環境との接続
- Agent Skills: タスク特化型の知識・手順
