## Code Wikiハイライト
- Code Wikiは公開リポジトリを取り込み、コード変更に応じてドキュメントを継続更新する自動保守サービス。
- Geminiを組み合わせたチャットエージェントがリポジトリ固有の知識で質疑に答え、関連コードへ即リンクできる。
- 「Gemini CLI」拡張で同様の仕組みをローカルで安全に使えるよう開発中で、ウェイティングリスト登録が案内されている。
