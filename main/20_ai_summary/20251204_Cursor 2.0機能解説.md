## 概要

AIコーディングツールの発展を振り返りながら、Cursor 2.0の機能や活用方法について詳しく紹介。2025年10月のバージョン2.0アップデートにより、専用モデル「Composer 1」とマルチエージェント実行機能などが追加された。

## AIコーディングツールの発展

### 2021年頃: GitHub CopilotがVS CodeにAI機能を導入

- GitHub Copilot、Cline、Roo Codeなど、VS Code拡張機能として動作するツールが登場

### 2023年頃: AIネイティブエディター「Cursor」の登場

- Cursor、Windsurf、Roo Codeなど、VS Code派生のIDEが登場
- リポジトリ全体の内容を理解して広範囲にわたる作業を実行できるエージェントを搭載

### 2025年前半: CLI型AIコーディングエージェントの登場

- Claude Code、Codex CLI、Gemini CLIなど、ターミナルから直接実行できるツールが登場

### 2025年後半: 各種AIツールとの連携を前提にしたツール群

- Serena、Spec Kit、cc-sddなど、既存のAIツールを拡張・連携させるアプローチ

## Cursor 2.0の主な機能

### コーディングエージェント

- **Askモード**: 探索・質問に特化、コードの変更は自動適用されない
- **Planモード**: 複雑なタスクを実行する前に計画を立てる
- **Agentモード**: コードベースを自律的に読み、複数ファイルの編集・ターミナル操作・テスト実行などを含むタスクを実行

### 統合ブラウザー

- HTML要素を直接指定しながらエージェントに指示を出したり、エージェントがブラウザーを操作して動作を確認

### 専用モデル「Composer 1」

- 複数ファイルにまたがる編集や大規模なリファクタリングに最適化
- 圧倒的な応答速度が特徴

### マルチエージェント実行

- 複数のエージェントを並列実行し、最適な結果を選んで反映

### コード補完機能

- 入力中にリアルタイムでコードを提案する高度なAI補完機能

### インライン編集機能

- 特定の領域に絞ってAIに編集を指示（`Cmd+K` / `Ctrl+K`）

## Cursorを使いこなすためのテクニック

### Planモードでの仕様駆動開発風コーディング

- 設計書として参照するためのマークダウンファイルを作業結果に応じて更新
- 機能追加する場合はその機能に関係するテストを作成
- 各コーディングタスクの最後に型チェッカー、リンター、フォーマッター、単体テストを実行

### Composer 1で爆速リファクター

- PlanモードでClaude Sonnet 4.5などを使って計画を立て、その後、Composer 1でBuildを実行

## なぜ、いままたCursorなのか

1. **Cursor 2.0による大幅な機能強化**: Composer 1、マルチエージェント実行など
2. **柔軟な開発スタイルを実現するエコシステム**: CLI型AIコーディングエージェントとの連携が容易
3. **エディターとしての完成度の高さ**: VS Codeベースで開発者に馴染み深い操作感
