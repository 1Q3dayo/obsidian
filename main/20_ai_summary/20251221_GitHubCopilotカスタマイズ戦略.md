## 概要

GitHub Copilotのカスタマイズ手法をLLMの仕組みから深掘りし、各手法の動作原理と最適な選択基準を解説。Agent Skills、MCP、カスタムインストラクション、カスタムエージェントの違いと使い分けを、コンテキストエンジニアリングの観点から説明。

## 主要ポイント

### LLMの基本仕組み
- システムメッセージ、ユーザーメッセージ、ツールメッセージ、アシスタントメッセージの4種類
- コンテキストエンジニアリング = システムメッセージの構築
- 外部環境との接点はツール呼び出し

### カスタマイズ手法の整理
- **カスタムインストラクション**: 指示を直接システムメッセージに追加
- **Agent Skills**: スキル定義ファイルへのポインタのみを追加（遅延ローディング）
- **MCP**: 外部環境とのやり取りを可能にするツールセット
- **カスタムエージェント**: 指示とツールセットを組み合わせて最適化

### 使い分け指針
- タスク特化型エージェント: カスタムエージェント
- 全体指針: カスタムインストラクション
- スクリプト・知識共有: Agent Skills
- 外部環境連携: MCPサーバー
- 簡単呼び出し: プロンプトファイル
