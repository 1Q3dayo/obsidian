## 要約

Claude Code Workflow StudioはVS Code拡張機能で、Claude Codeのワークフロー（カスタムコマンド・サブエージェント連携等）をノードベースのビジュアルキャンバスで設計・編集できるツール。GitHubスター1,100+、マージ済みPR 297件の活発なプロジェクト。

従来はMarkdownファイルの手動作成が必要だったワークフロー設定を、ドラッグ&ドロップ操作で直感的に構築可能にする。設定ファイルの複雑さ、エージェント連携の可視化困難、チーム間共有の煩雑さという3つの課題を解決する。

インストール方法から基本操作、実践的なユースケースまでをハンズオン形式で解説している。
