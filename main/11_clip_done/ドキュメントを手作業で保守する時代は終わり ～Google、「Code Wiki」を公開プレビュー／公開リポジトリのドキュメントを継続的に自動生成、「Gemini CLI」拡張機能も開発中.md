Google、「Code Wiki」を公開プレビュー

　米Googleは11月13日（現地時間）、「Code Wiki」（codewiki.google）のパブリックプレビューとしてリリースした。AIを活用してパブリックなソースコードリポジトリを取り込み、ドキュメントを生成・ホストし、ソースコードの変更に応じて継続的に内容を自動更新してくれるドキュメント保守サービスだ。

![](https://asset.watch.impress.co.jp/img/wf/docs/2063/281/image2.png) パブリックなソースコードリポジトリを取り込み、ドキュメントを生成・ホストし、ソースコードの変更に応じて継続的に内容を自動更新

　「Code Wiki」のメリットは、大きく分けて下の3つだ。

- **常に最新の状態** ：「Code Wiki」はコードベース全体をスキャンし、変更を検知すると自動でドキュメントを更新する。ドキュメントが古くなり、実際のソースコードと齟齬が出ることはない
- **リポジトリの専門家** ：「Code Wiki」にはコードベースに関する知識を備えた「Gemini」のチャットエージェントが付属。一般的な事柄を扱う「Gemini」よりも深く、専門的な受け答えが可能
- **ソースコードとドキュメントの統合** ：すべてのWikiセクションとチャットの回答には関連するコードファイルと定義に直接ハイパーリンクされており、疑問があればソースコードの当該部分を直接確認できる

　同社は『新参のコントリビューターでも1日目に最初のコミットが可能』『新しいライブラリがあっても、上級開発者ならたった数分で概要を把握できる』『手動でドキュメントを整備する時代は終わった』と、その先進性をアピールしている。

　また、「Code Wiki」専用の [「Gemini CLI」](https://forest.watch.impress.co.jp/docs/news/2025870.html) 拡張機能も開発中とのこと。これがあれば、「Code Wiki」と同じシステムをローカルリポジトリで安全に利用できる。興味のある開発者は、 [ウェイティングリスト](https://developers.google.com/profile/badges/community/sdlcagents/gca-agents?hl=ja) に登録しておくとよいだろう。拡張機能がリリースされれば、通知される。
